# visual-qa

视觉质检：截图缺陷、对照参考图、帧序列运动检查（Gemini / 原生视觉）。

**安装并使用：** 把 GitHub 仓库 [`JanusChoi/jc53-skills`](https://github.com/JanusChoi/jc53-skills) 里的 [`visual-qa/`](https://github.com/JanusChoi/jc53-skills/tree/main/visual-qa) 装进你所用 Agent 的 skills 目录（不必克隆整仓），例如：

```bash
npx --yes degit JanusChoi/jc53-skills/visual-qa <你的-skills目录>/visual-qa
```

然后**新开对话**，用下方触发话术调用。适用于任何会加载 Agent Skills（目录内含 `SKILL.md`）的工具（Cursor、Claude Code、Codex、Hermes 等）。

<details>
<summary>无 npx 时 / 路径示例</summary>

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/JanusChoi/jc53-skills.git /tmp/jc53-skills
cd /tmp/jc53-skills && git sparse-checkout set visual-qa
mkdir -p <你的-skills目录>
ln -sfn /tmp/jc53-skills/visual-qa <你的-skills目录>/visual-qa
```

常见 skills 目录：`~/.cursor/skills/`、`~/.claude/skills/`，其它工具以各自文档为准。
</details>

## 触发话术

```text
visual-qa <截图或目录> [参考图]
```

权威执行协议见同目录 [`SKILL.md`](./SKILL.md)（及可选的 `references/`、`scripts/`）。
