# ABC 谱语法简明参考（10 分钟能学会）

参考：[ABC 完整规范](https://abcnotation.com/wiki/abc:standard)

我们这套简化版只支持最常用的子集，足够写 24s-120s 的 BGM。

## 头（每行 `K:` 是首部/字段）

```
X:1              ← 编号
T:My BGM         ← 标题
M:4/4            ← 拍号
Q:120            ← BPM（每分钟拍数）
K:C              ← 调号（默认 C major）
L:1/8            ← 默认音符长度（L/whole，1/8 = 0.5 拍）
```

## 音符

| 写法 | 含义 |
|------|------|
| `C` | C 大调 C4（中音 do） |
| `c` | C 大调 C5（高八度） |
| `C,` | 比 C 低八度 |
| `C'` | 比 C 高八度 |
| `C2` | C 持续 2 个 L（默认 1 个 L = 0.5 拍，所以 2 个 L = 1 拍） |
| `C/` | C 持续半个 L（0.25 拍） |
| `C4` | C 持续 4 个 L（2 拍） |

## 小节

- `|` 小节线
- `|:` 反复开始
- `:|` 反复结束
- `||` 结束

## 注释

`%` 开头到行末是注释。

## 示例（24s BGM）

```
X:1
T:cat-04-snowman bgm
M:4/4
Q:120
L:1/8
K:C
% scene seg01 钩子（安静，钢琴单音）
|: C2 E2 | G2 E2 | F2 D2 | E4 :|
% scene seg02 起（加一层）
|: C2 E2 G2 E2 | F2 D2 C2 E2 | G2 E2 F2 D2 | C4 :|
% scene seg03 升（爆发）
|: C2 E2 G2 C2 | F2 D2 E2 G2 | C2 E2 G2 C2 | F2 E2 D2 C2 :|
% scene seg04 落（安静收尾）
|: E2 D2 | C4 :|
```

时长：120 BPM × 4 段 × 6s = 48 拍 = 24s（每小节 4 拍 × 6 小节 = 24 拍，120 BPM = 0.5s/拍，24 拍 = 12s，**所以实际是 12s** — 想要 24s BGM 就把每段重复写两遍，或加一个 `L:1/4` 让音符变长）。

## 调试技巧

- 跑 `python3 abc_synth.py score.abc out.wav` 看时长对不对
- WAV 时长 ≈ BPM / 60 × 总拍数
- 调音：换 K:（`K:G` = G 大调，所有音高 +5 半音）
- 调密度：换 L:（`L:1/4` = 0.25 拍/音符，密度减半）

## 不支持的（简化版）

- 装饰音（rolls, ornaments）
- 力度（dynamics, ! ! ! !）
- 歌词（w:）
- 复杂调号（带升降号的，eg K:D = D major 有 F#/C#）
- 三和弦 / 多声部和声（一次只能写一个旋律线）

如果需要这些，升级到 fluidsynth + SoundFont 真乐器采样（参见 SKILL.md 升级指引）。
