## 3 秒钩子检查（seg01 内）
- [ ] seg01 末 1 秒必须有显著变化（光影/姿态/物件）
- [ ] seg01→seg02 不能"无缝"

## 中段爆发检查（seg09-seg12 区间，必有一次硬切）
- [ ] seg09 / seg10 / seg11 / seg12 内必有一次 cut（帧差 ≥8%）
- [ ] 标记哪一段是爆发点：seg__

## 末段静一拍检查（seg16→seg17）
- [ ] seg16 末 0.5s 必须"静止/慢动作"
- [ ] seg17 第一拍启动必须显著

## 4 段小高潮检查（每幕结尾）
- [ ] seg04 末（1 幕收）—— 静 → 起 转折
- [ ] seg08 末（2 幕收）—— 起 → 升 转折
- [ ] seg16 末（4 幕收）—— 升 → 落 转折
