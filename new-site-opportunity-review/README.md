# new-site-opportunity-review

评估一个词/主题是否值得做新站（ship / skip / validate）。

**安装并使用：** 把 GitHub 仓库 [`JanusChoi/jc53-skills`](https://github.com/JanusChoi/jc53-skills) 里的 [`new-site-opportunity-review/`](https://github.com/JanusChoi/jc53-skills/tree/main/new-site-opportunity-review) 装进你所用 Agent 的 skills 目录（不必克隆整仓），例如：

```bash
npx --yes degit JanusChoi/jc53-skills/new-site-opportunity-review <你的-skills目录>/new-site-opportunity-review
```

然后**新开对话**，用下方触发话术调用。适用于任何会加载 Agent Skills（目录内含 `SKILL.md`）的工具（Cursor、Claude Code、Codex、Hermes 等）。

<details>
<summary>无 npx 时 / 路径示例</summary>

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/JanusChoi/jc53-skills.git /tmp/jc53-skills
cd /tmp/jc53-skills && git sparse-checkout set new-site-opportunity-review
mkdir -p <你的-skills目录>
ln -sfn /tmp/jc53-skills/new-site-opportunity-review <你的-skills目录>/new-site-opportunity-review
```

常见 skills 目录：`~/.cursor/skills/`、`~/.claude/skills/`，其它工具以各自文档为准。
</details>

## 触发话术

```text
new-site-opportunity-review <候选词>
```

权威执行协议见同目录 [`SKILL.md`](./SKILL.md)（及可选的 `references/`、`scripts/`）。
