# Druckenmiller Framework

> 把 Druckenmiller 40 年一手法则（公开访谈、致客户信、13F、公开演讲）压成
> **决策树 + 流程**，帮你在面对新主题/新标的/新宏观时，30 分钟内过一遍
> "他会不会这么做"的自检。
>
> **数据基础**：截至 v1 仅基于 Morgan Stanley "Hard Lessons" 2026-02-27 访谈。
> 其他原话资料（Tangen 访谈 / CNBC / Schwager 早期章节 / 13D Research）未入库。

---

## Inputs to collect

| 字段 | 必填 | 说明 |
|------|------|------|
| 当前决策场景 | ✅ | 新 thesis / 持仓复审 / 宏观仓位调整 / 鱼尾判断 |
| 涉及标的/资产 | ✅ | 单只 / 一组 / 宏观资产 |
| 当前立场 | ✅ | long / short / 观望 / 减仓 |
| 当前周期 | ✅ | 短线 / 中线 (1-6 月) / 长线 (6 月+) |
| 核心 thesis | ✅ | 1-2 句话，因果链 |

## Procedure: 4 步流程

### Step 1：前瞻 — 18-24 月共识会怎么重定价？

**核心问题**：未来 18-24 个月，**市场主流叙事**会怎么变？现在的共识 12 个月后会被怎么重新定价？

**Druckenmiller 原话**（Hard Lessons 2026-02-27）：
> "If you look at today, you're not going to make any money. You have to look ahead, think about what might change, and how investors will view things in the future."

**自检清单**：

- [ ] **共识 18 月后会重新定价吗？** 现在的市场叙事是什么？18 月后哪些变量会让叙事重写？
- [ ] **驱动因素是结构性还是周期性？** 结构性 = 供应瓶颈 / 技术革命 / 人口；周期性 = 库存 / 利率 / 汇率
- [ ] **共识拥挤度如何？**（注意：他反对"逆向 = 必然正确"——"the crowd is right 80% of the time"）
- [ ] **你的 thesis 是"信仰"还是"交易"？** 信仰 = 18-24 月持有不看；交易 = 1-3 月事件驱动

**Output**：一段不超过 100 字的前瞻判断 + 一句话回答"主流叙事会怎么变"。

---

### Step 2：瓶颈 — 押的是什么"稀缺"？

**核心问题**：这个 thesis 赚钱的真正驱动是什么？是"需求扩张"还是"供应瓶颈"？**瓶颈比需求更可靠**。

**Druckenmiller 原话**（Hard Lessons 2026 谈铜）：
> "For the next eight years there's no meaningful new supply; it's extremely tight. Clearly, there will be huge demand growth from AI and data centers."

**自检清单**：

- [ ] **供应侧有硬约束吗？**（矿山 7-10 年开发周期 / 电网 3-5 年 / 一线土地规划锁定 / 训练算力瓶颈）
- [ ] **需求侧是"真实需求"还是"情绪需求"？** 真实需求 = 订单 / 合同 / 装机量；情绪需求 = 叙事驱动
- [ ] **供需缺口时间维度？** 18-24 月内会持续扩大 / 收窄？
- [ ] **是否有"非性感但赚钱"的结构？**（他重仓 Teva 6 P/E 的"非 AI 转型股"案例）

**Output**：一句话回答"我押的稀缺是什么？是供应瓶颈还是需求扩张？"。

---

### Step 3：证伪 — 什么会让这个 thesis 死掉？

**核心问题**：**进场第一天就写下"什么会让这个 thesis 死掉"**——"温水煮青蛙"是最大的风险。

**Druckenmiller 原话**（Hard Lessons 2026）：
> "You'll keep making mistakes, you'll keep getting emotional... But you have a gift, so stop beating yourself up for 48 hours or more."

**自检清单**（强制 3-5 条，写在 thesis 文件的第一页）：

- [ ] **数据型证伪**（先于仓位触发）：例 "铜矿新增产能 > X 万吨/年" / "美国就业数据连续 3 月 < 10 万"
- [ ] **事件型证伪**：例 "央行重新宽松" / "AI 资本开支被主流砍单" / "OpenAI 收入连续两季环比下降"
- [ ] **价格型证伪**：例 "跌破关键技术位" / "趋势指标走坏 + 连续 X 日未收回"
- [ ] **叙事型证伪**：例 "市场重新定价为'通缩'" / "共识转向反向叙事"

**Output**：3-5 条证伪红线（每条必须先于仓位触发，不是事后总结）。

---

### Step 4：执行 — 仓位、表达工具、扣扳机

**核心问题**：对的时候赚多少？错的时候亏多少？**仓位规模 > 入场时机**。

**Druckenmiller 原话**（从索罗斯学到的）：
> "The key isn't whether you are right or wrong, but how much you make when you're right, and how much you lose when you're wrong."

**自检清单**：

- [ ] **表达工具选对了吗？** 铜/原油 = 期货 rolling nearby（不是矿股/油股，β 太大）；美债 = 期货或 ETF；黄金 = 期货或 GLD；个股 = 龙头股或期权
- [ ] **单笔最大风险是多少？** 建议单笔 < 总组合 30%
- [ ] **有反脆弱对冲吗？** 至少 1 条 hedge：黄金 / 短债 / 做空相关性资产 / 现金
- [ ] **"扣扳机"前置条件是否清晰？** 趋势确认 / 突破关键位 / 共识扩散 / 资金面配合

**Output**：完整的"仓位 + 表达工具 + 反脆弱对冲 + 入场触发"四件套。

## Decision Trees: 5 棵决策树

### 决策树 1：新主题我该不该进？（前瞻 + 瓶颈）

```
新主题信号进来
    │
    ├── 18-24 月前瞻是什么？─→ 模糊 ──→ 跳过（"我不懂就别押"）
    │       │
    │       └── 清晰（共识会重定价）
    │               │
    │               ├── 是供应瓶颈？ ──→ 进入决策树 2
    │               ├── 是需求扩张？ ──→ 进入决策树 2（但加严）
    │               └── 是周期性回暖？ ──→ 进入决策树 3
```

### 决策树 2：拥挤度判断（"逆向 = 错"vs"逆向 = 信仰"）

```
共识 / 拥挤度
    │
    ├── 拥挤且我看空 ──→ 不做（"the crowd is right 80% of the time"）
    ├── 拥挤且我看多 ──→ 可做，但**必须有更高门槛**（基本面 + 趋势 + 资金面三重确认）
    ├── 不拥挤且我看多 ──→ 信仰持仓（"When I have extreme conviction and no one believes, I really like it"）
    └── 不拥挤且我看空 ──→ 信仰做空（但**做好流动性风险**）
```

### 决策树 3：持仓该不该撤？（鱼尾 / can't stand success）

```
持仓浮盈 > 50%
    │
    ├── 估值是否已透支？ ──→ 远期 PE > 历史 80% 分位 + 业绩增速放缓
    │       │
    │       └── 否 ──→ 拿住（信仰不撤）
    │       │
    │       └── 是 ──→ 进决策树 4
    │
    ├── 趋势是否走坏？ ──→ 主要趋势指标转弱 + 连续 X 日走弱
    │       │
    │       └── 否 ──→ 拿住
    │       └── 是 ──→ 减仓 50%
    │
    └── 综合判断 ──→ 出现"can't stand success"心理触发
            │
            └── 参考 NVDA 案例：他 150 入 / 800 卖 / 5 周后到 1400（"5 weeks later it went to $1,400, and I felt terrible"）
            │
            └── 教训：**人最难的是拿住盈利，不是买对**——鱼尾判断要前置，不要事后
```

### 决策树 4：反脆弱对冲怎么搭？

```
主仓位（信仰 70-85%）
    │
    ├── 宏观对冲（10-15%）──→ 黄金 / 短债 / 美元 / VIX
    │       │
    │       ├── 看多美元 ──→ 做空美债（"If I'm right on disinflationary growth, maybe break even; if wrong, strong growth triggers inflation"）
    │       ├── 看空美元 ──→ 黄金 + 日元
    │       └── 不确定 ──→ 短债 + 现金（保本为主）
    │
    └── 现金保留（5-15%）──→ 等待扣扳机
```

### 决策树 5：表达工具选什么？

```
标的方向
    │
    ├── 铜 / 原油 / 大宗 ──→ 期货 rolling nearby（**不押矿股/油股**——β 太大）
    ├── 美债 / 利率 ──→ TLT / IEF / 期货
    ├── 黄金 ──→ 期货或 GLD（**不押金矿股**——运营 β 干扰）
    ├── 货币 ──→ DXY / UUP / 直接 NDF
    ├── 个股 ──→ 龙头股 / 行业 ETF / 个股期权
    └── 指数 ──→ ETF / 期货
```

## 金句参考卡（7 条）

> 使用方式：每条 1 句话，需要时直接引用，写公众号时作为"对标大师"段落。

1. **前瞻**："If you look at today, you're not going to make any money. You have to look ahead."
2. **逆向**：*"I think contrarian investing is overrated. Soros often said, the crowd is right 80% of the time. You just can't get caught in the other 20%."*
3. **信仰**："When I have extreme conviction and no one else believes, I really like that—it makes me more confident."
4. **扣扳机**："My advantage isn't IQ—it's the ability to pull the trigger."
5. **仓位**："The key isn't whether you are right or wrong, but how much you make when you're right, and how much you lose when you're wrong."
6. **瓶颈**："For the next eight years there's no meaningful new supply; it's extremely tight."
7. **心理**："You'll keep making mistakes, you'll keep getting emotional... stop beating yourself up for 48 hours or more."

## 不使用此 skill 的场景

- **个股买卖时机**：用 `equity-snapshot`（一页式研究快照）
- **盘后市场复盘**：用 `market-daily-review`
- **业绩点评**：用 `earnings-flash`
- **纯技术分析**：他本人说技术分析已失效 80%——本 skill 不教技术分析
- **资产配置全框架**：本 skill 是决策框架，不是资产配置模型
